# Smart Library Management System

## Description
A beginner-friendly library management project using Python, Tkinter, and SQLite.

## Features
- Add books
- Search books
- Delete books
- View all books

## Technologies Used
- Python
- Tkinter
- SQLite

## How to Run
1. Install Python
2. Download the project
3. Run:

python main.py
